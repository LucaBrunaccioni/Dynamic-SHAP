# Dynamic-SHAP
Source code of the paper: 

L. Brunaccioni, F. De Fusco, M. Vallerio. "Dynamic SHAP: time-resolved explainable AI for batch processes", published in Computers and Chemical Engineering, 2026, https://www.sciencedirect.com/science/article/pii/S0098135426001705

The repository contains: (i) the DSHAP class (featuring methods for generating continuous and cumulative D-SHAP profiles), (ii) two synthetic datasets (together with their respective Random Forest models) used in the paper to benchmark the D-SHAP methodology, and (iii) example usage of the DSHAP class for the applications metioned above.
